Política de privacidad

Última actualización: 18 de noviembre de 2026

Esta política explica cómo trata los datos la aplicación Leo Tensor publicador, una herramienta interna que usa el propio canal de YouTube Leo Tensor para gestionar sus publicaciones. No es una aplicación abierta al público: solo la usa la cuenta del canal.

Qué datos usa

Con el permiso expreso de la cuenta del canal, concedido mediante la pantalla de autorización de Google, la aplicación accede a la API de YouTube para:

  • Subir y programar vídeos en el canal Leo Tensor, con su título, descripción y etiquetas.
  • Leer la información del canal: nombre, identificador y lista de vídeos propios.
  • Leer las estadísticas del canal (YouTube Analytics): visualizaciones, retención, me gusta, comentarios y compartidos de los vídeos propios, para saber qué contenido funciona mejor.
  • Leer los comentarios públicos de los vídeos propios, para detectar qué temas pide la audiencia.

La aplicación no accede a datos de otras cuentas de Google ni a datos privados de los espectadores.

Dónde se guardan

El permiso de acceso (token) y las estadísticas se guardan únicamente en el ordenador del responsable del canal. No se suben a servidores de terceros.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden ni se usan para publicidad.

Uso limitado de los datos de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google se ajustan a la Política de Datos de Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.

La aplicación usa los servicios de la API de YouTube. Al usarla se aplican también las Condiciones del Servicio de YouTube y la Política de Privacidad de Google.

Cómo retirar el permiso

El acceso se puede revocar en cualquier momento desde la página de permisos de la cuenta de Google. Al revocarlo, la aplicación deja de poder subir vídeos o leer estadísticas, y los datos guardados en local se pueden borrar pidiéndolo por correo.
